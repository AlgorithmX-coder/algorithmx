name: design-bold-not-subtle
description: User's visual-design bias for the landing-v2 UI — push bolder/more futuristic, not subtle
metadata:
  type: feedback
---

For landing-v2 UI work (e.g. the top Nav at [app/components/landing-v2/Nav.tsx](app/components/landing-v2/Nav.tsx)), the user repeatedly finds polished-but-restrained results "too subtle / too timid." They want noticeably bold, futuristic, premium, "live OS / sci-fi HUD" presence — more 3D, more visible motion, stronger branding — while still production-quality (reduced-motion safe, no layout shift, responsive).

**Why:** A prior conservative pass on the header was rejected for being too understated.

**How to apply:** When asked to "improve/polish" landing-v2 visuals, err toward stronger, more dimensional, more animated treatments rather than minimal tweaks — but keep it tasteful (no arcade/cartoon glow) and keep the existing reduced-motion + responsive guardrails intact.
